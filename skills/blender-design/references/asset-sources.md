# Asset-source directory

Primary pages reviewed 2026-10-26. Choose by the brief, item, terms, and available formats; listing order expresses no preference. These descriptions verify published offerings/access guidance, not successful automated access, account entitlements, downloaded bytes, or Blender import compatibility. No assets, accounts, add-ons, or integrations were acquired for this directory. Recheck current item terms when using an asset. Apply the [shared workflow](assets.md).

| Source | What it offers | Access and download routes | Where to check rights |
|---|---|---|---|
| [Poly Haven](https://polyhaven.com/) | Models, PBR textures, and HDRIs. | Website item/variant downloads and a documented [public API](https://polyhaven.com/our-api). This package's [optional utilities](polyhaven.md) cover only a bounded provider-specific route. | [Asset license and website terms](https://polyhaven.com/license), plus the API terms linked there. Assets are CC0; other website content is not thereby CC0. Live API results should identify Poly Haven. |
| [ambientCG](https://ambientcg.com/list) | [PBR materials/atlases/decals, HDRIs, models, and other asset types](https://docs.ambientcg.com/asset-types/). | Website variant downloads; a documented [search/download API](https://docs.ambientcg.com/api/). The API documentation cautions about service stability. No ambientCG helper is included here. | [License](https://docs.ambientcg.com/license/): downloadable assets and material preview renders are CC0. Check the selected item's files and applicable access terms; do not extend that statement to arbitrary site content. |
| [Kenney](https://kenney.nl/assets) | Game asset packs, including stylized 3D models; the wider catalog also includes 2D, UI, and audio. | Individual pack downloads, with an optional donation; an All-in-1 bundle is also offered. The [Mini Arena page](https://kenney.nl/assets/mini-arena) demonstrates a 3D pack and its download/license entry. | [Support/licensing FAQ](https://kenney.nl/support) identifies game assets on asset pages as CC0 and points to each asset page/included license. This is not a license claim about every Kenney product or its logo. |
| [Quaternius](https://quaternius.com/) | Low-poly/stylized model packs, characters, environments, and animations. | Pack-page download links and optional supporter products. [Ultimate Nature](https://quaternius.com/packs/ultimatenature.html) lists FBX, OBJ, and Blend; formats and included content vary by pack. | [FAQ](https://quaternius.com/faq.html) states model assets are CC0; verify the specific pack's license and contents, especially separately offered products. |
| [NASA 3D Resources](https://science.nasa.gov/3d-resources/) | Mission-related models, some printable assets, and images/textures. | Browse the resource hub and individual files; NASA links an official [GitHub mirror](https://github.com/nasa/NASA-3D-Resources). Formats and scientific fidelity vary by item. | Item credits/notices and [NASA media usage guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/). NASA-produced content is generally not copyrighted in the US, with third-party exceptions and separate branding, endorsement, and personal-image restrictions. Acknowledge NASA. Do not label the catalog universally CC0. |
| [BlenderKit / Blendkit](https://www.blendkit.com/) | Models, materials, HDRIs, scenes, brushes, and other asset categories. [Blendkit is the current name](https://www.blendkit.com/news/goodbye-blenderkit-hello-blendkit/). | Official [Blender add-on and documentation](https://github.com/BlenderKit/Blendkit): a free selection is available without an account; broader access uses a Full plan. Website browsing is an entry point, not proof of unauthenticated direct-file/API access. No integration is included here. | The item's license, [license descriptions](https://www.blendkit.com/docs/licenses/), and [licensing FAQ](https://www.blendkit.com/docs/licenses/licensing-faq/). CC0 and royalty-free assets coexist. Royalty-free use in rendered/derived work does not grant unrestricted resale or redistribution of source assets/scenes. Check delivery of an editable `.blend` separately. |

## What was checked

The linked provider-controlled pages were opened and read for these summaries. The pack examples establish what those specific pages advertise, not what all packs contain. The Blendkit repository describes its official add-on/access route; the add-on was not installed. No new provider download, API request, import, or render test was performed. Poly Haven's older acquisition/import results remain separately scoped in [its utility guide](polyhaven.md).

These are original source-linked summaries. No new full third-party page capture is redistributed in the public package. Existing research captures, qualifications, and references remain preserved under the [archive policy](../../../docs/archive.md).
