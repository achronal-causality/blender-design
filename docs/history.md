- Live search and metadata inspection succeeded. The `dirty_football` 1K native variant downloaded as four files totaling 3,530,774 bytes; declared size/MD5 and locally recorded SHA-256 checks passed.

Three 1024-pixel textures were packed, provenance embedded, and an unrelated sentinel object preserved. No imported drivers or constraints were present in this selected collection.
- The initial check incorrectly treated a retained library record as an active external dependency. A diagnostic found zero linked IDs; the record disappeared on saved-file reopen. The failed assertion and diagnostic remain in project evidence.
- A 512×512 Cycles CPU render was inspected visually. The saved scene was copied to another path and reopened/rendered under a per-process OS sandbox denying network and reads of the original acquisition. Separate probes confirmed both denials. The reopened scene retained its three packed textures and provenance, with zero linked IDs or library records. Decoded RGB pixels matched the original render exactly in this check; PNG container hashes differed. This is not a cross-platform determinism claim.
- Source/catalog metadata is not a substitute for inspecting the selected level of detail. General asset compatibility, HDRI placement and automatic material reconstruction remain task-specific and untested here.
