# Licensing review

Reviewed 2026-10-26. This is a distribution inventory and recorded decision, not a blanket legal clearance.

## Authorized allocation

Julian Turner explicitly authorized GPL-3.0-or-later for original code and CC BY-SA 4.0 for original documentation. The default release carries this allocation, the full GPL text, and the CC license URI. Code examples in documentation use the code license. Metadata uses the prose license to the extent original rights exist. Third-party rights remain excluded.

## Default package review

- Original reports, claim ledger, module explanations, indexes, failure analysis, and working instructions: retained with source attribution and scope.
- Original helper/demo/example scripts: retained under GPL-3.0-or-later. Historical installers/fetchers/receipt writers are outside the default release.
- Captured Blender HTML/RST/source, community posts, external project files, and extracted articles: excluded from the public payload. File hashes and source/reading metadata remain.
- Copied Poly Haven website, API spec, and pinned terms: excluded. The original policy summaries in the public package link to the primary sources and distinguish summary from capture in acquisition receipts.
- Generated Python caches: excluded from the public payload; original bytes remain in the private snapshot.
- Attributed excerpts and API signatures embedded in original analysis: preserved with their existing source context; not relicensed as third-party ownership.

## Source distinctions

Blender publishes licensing guidance for Python API scripts at https://www.blender.org/about/license/ and https://www.blender.org/support/faq/. The current release uses GPL-3.0-or-later for original code, including host helpers, avoiding mixed code-license instructions.

Poly Haven's [license page](https://polyhaven.com/license) states that assets are CC0 and separately restricts redistribution of other website content. Its [API page](https://polyhaven.com/our-api) describes free API access, including commercial use, and visible source identification. Neither is treated as a license for arbitrary captured web pages.

## Archive publication remains unresolved

The companion ZIP is a private preservation artifact, not a public release asset. Per-source license texts, attribution requirements, and redistribution permissions have not been established for every captured page, issue report, or external repository file. No automatic publication command includes that ZIP. All captures remain available locally; public archive access needs a separate clearance decision. This does not block the curated default package from being reviewed for publication.
